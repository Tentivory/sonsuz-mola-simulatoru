# Sonsuz Mola Simülatörü

## Bu Yazılım Neden Var?

Çünkü iş hayatının en büyük yalanı "kısa mola" kavramıdır. Bu repo, o yalanı sonsuza kadar uzatmak için tasarlandı. Gerçek bir Python scripti içerir. Çalıştırın ve mola alın. Sonsuza kadar.

### Özellikler
- Sonsuz döngü (gerçekten sonsuz, Ctrl+C'ye kadar)
- Rastgele komik Türkçe mola bahaneleri
- Her saniye artan sayac
- Hiçbir işe yaramaz ama çok işe yarar
- Bilimsel olarak kanıtlanmış mola uzatma teknikleri

### Nasıl Kullanılır?
```bash
python sonsuz_mola.py
```

Sonra oturun ve izleyin. Ya da git, gerçekten mola al.

### Uyarılar
- İşvereniniz görürse kovulabilirsiniz. Ama bu da bir mola sebebidir.
- Bilgisayarınız ısınabilir. Mola alın.
- Bu yazılım ciddiye alınmamalıdır. Ama alın.
